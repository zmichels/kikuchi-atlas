# KIKU-T078: Publish the Ni v0.1 Reference Pack descriptor and release boundary

## Description

Make the narrow public resource self-explanatory: what it contains, how to
verify and reproduce it, what source and method it uses, and what it does not
establish scientifically.

## Acceptance Criteria

- [x] The descriptor links the recipe, source inventory, verifier, baseline,
  attribution, and authoritative claim boundary.
- [x] It states the current checked result and recipe digest without treating a
  source-bound baseline as independent truth.

## Completion Evidence

The new Reference Pack catalogue and Ni descriptor provide the public entry
point; the earlier intake record is updated from pending scope to this approved
lightweight release.
